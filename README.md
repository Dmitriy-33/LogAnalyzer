# Log Analyzer — анализатор логов Nginx

Анализатор логов веб‑сервера Nginx для сбора статистики по URL (среднее и максимальное время ответа, количество запросов) и генерации HTML‑отчёта.

## Возможности

- Парсинг логов Nginx (в том числе gzip‑архивов).
- Поиск последнего подходящего лог‑файла по дате в имени.
- Сбор статистики: топ URL по времени ответа, количество запросов, ошибки парсинга.
- Проверка порога ошибок парсинга: если доля ошибочных строк превышает заданный порог — анализ прерывается.
- Генерация HTML‑отчёта с таблицей и краткой сводкой.
- Логирование через `structlog`.


## Требования

- Python 3.13+
- Poetry для управления зависимостями

## Установка и запуск

### Установка зависимостей
poetry install

### Запуск
poetry run python -m log_analyzer.main
